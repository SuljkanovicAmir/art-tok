# Timeline Game (2026-11-07)

A daily browser game at `/timeline`. Players drag 7 paintings into history, oldest to newest,
then challenge a friend to beat their score. It runs in the browser with no backend.

It replaced Thirty Strokes, a copy-the-painting game that was built and removed the same
day because it felt too hard and too complicated.

## How it works

- **Round:** one painting starts on the timeline, and the player places 7 more. Each wrong
  placement moves the card to its true position and costs that point.
- **Placing a card:** drag it, or tap a gap. Gaps are real buttons, so keyboards and screen
  readers can play. Letting go over the tray cancels the move.
- **Feedback:** a message above the cards says whether the placement was right, and a tick
  or cross appears beside the year. The next card appears at once, so the game never pauses.
- **Daily set:** `dealRound` is seeded by the puzzle number, which counts UTC days from
  2026-11-07, so everyone gets the same paintings.
- **Fairness:** paintings in a round are at least 12 years apart, so no placement is a guess
  between near-identical dates.
- **Competing:** results share as spoiler-free text plus a link such as `?p=12&vs=5`. The
  friend plays the same set and sees who won.
- **New round:** practice with a random set. It does not affect the daily record or streak.

## Files

- `src/pages/TimelinePage.tsx`: round state, intro and challenge handling
- `src/components/timeline/`: `TimelineBoard` and `TimelineResult`
- `src/utils/timeline/game.ts`: dealing, rules, ranks and challenge links
- `src/utils/timeline/paintings.json`: generated by the script below
- `scripts/timeline/build-paintings.mjs`: builds the set from `paintings.source.json`

## Paintings

72 Met European Paintings highlights from 1344 to 1913, 2.4 MB in total. The build confirms
each work is public domain and has a date range of 4 years or less. Images are self-hosted
in `public/game-paintings/`, so the game does not depend on a museum API at runtime.

Titles that reveal their date are excluded, such as *Young Lady in 1866*. To grow the set,
add object IDs to `paintings.source.json` and rerun the script. This changes future daily
sets. Met blocks bursts of requests, so the script waits between calls.

The set is all European, with a heavy cluster in the late 1800s. Adding American and Asian
works would widen it.

## Deployment

`deploy.yml` copies `index.html` to `404.html`. GitHub Pages has no server routing, so deep
links such as `/art-tok/search` returned 404 before this. Challenge links depend on it.
